## Gamma Function

for integers, [Factorial](Factorial) $x! = x\, (x - 1)!$ 
what if $x$ is not an integer? 

can use the Gamma Function:

$x! = \Gamma(x) = \int\limits_{t=0}^\infty t^x\, e^{-t}\, dt$
