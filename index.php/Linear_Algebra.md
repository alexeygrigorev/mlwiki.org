## Linear Algebra
The fundamental problem of Linear Algebra is solving a [System of Linear Equations](System_of_Linear_Equations)
- [Matrices](Matrix) are the main building blocks of linear algebra
- The easiest way to solve a system is [Gaussian Elimination](Gaussian_Elimination)
  - its byproduct is [LU Decomposition](LU_Decomposition)
- A system $A \mathbf x = \mathbf 0$ is called [homogeneous](Homogeneous_Systems_of_Linear_Equations) 
- Matrices form [Vector Spaces](Vector_Spaces) and have subspaces. 
  - There are [Four Fundamental Subspaces](Four_Fundamental_Subspaces)
  - [Column Space](Column_Space), [Row Space](Row_Space), [Nullspace](Nullspace) and left Nullspace
  - each (sub)space have a [basis](Basis_%28Linear_Algebra%29)
- by knowing the [Rank](Rank_%28Matrix%29) we can know the dimensionality of these subspaces
