# Ubersuggest Baseline

Use Ubersuggest mainly as a research source and as a second opinion to Ahrefs.

## Keywords by Traffic

Export:

```
keyword
position
volume
estimated visits
URL
```

## Top Pages by Traffic

Export:

```
URL
estimated visits
keywords
backlinks
```

## Backlinks

Export when useful:

```
source URL
target URL
anchor
link metrics
```

## Site Audit

Run one baseline audit.

Use it mainly to compare findings with Ahrefs rather than to duplicate all analysis.

If Ahrefs and Ubersuggest disagree, investigate methodology and URL coverage instead of assuming one system is automatically correct.

## Do not do broad keyword research yet

Do not export huge keyword-idea datasets during baseline.

First:

1. complete the baseline
2. segment existing pages
3. select one topic cluster
4. then perform focused keyword research

## Focused keyword research later

For a chosen topic cluster, export:

```
keyword
volume
SEO difficulty
CPC
SERP information
```

Then combine:

- GSC queries
- Ahrefs keywords
- Ubersuggest keyword ideas
- SERP observations

into:

```
query → intent → cluster → existing page → action
```
